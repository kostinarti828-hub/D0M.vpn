# Dom.VPN Telegram bot

Telegram Mini App Dom.VPN с тарифами на 1, 3, 6 и 12 месяцев. Оплата принимается только в Telegram Stars; после подтверждённой оплаты бот отправляет VLESS-ссылку из секретной переменной окружения.

## Запуск в Windows

Требуется Node.js 20 или новее. Бот и Mini App-сервер запускаются одним процессом; Express раздаёт страницу и каталог `/api/plans`.

1. Установите бота и Mini App-сервер на хостинг с публичным HTTPS-доменом. Telegram не открывает Mini App с локального адреса `localhost` или обычного HTTP.
2. В `.env` задайте `WEB_APP_URL=https://ваш-домен/` и `TELEGRAM_BOT_TOKEN`. URL должен вести на этот же сервер; он отдаёт Mini App и API цен. Настройте хостинг на запуск `npm start` и передачу переменной `PORT` (по умолчанию `3000`).
3. Запустите бота, откройте его в Telegram от имени менеджера и отправьте `/start`, затем `/id`. Впишите показанный ID в `ADMIN_CHAT_ID` и перезапустите бота. Telegram не разрешает боту первым начинать личный диалог.
4. В Railway → **Variables** добавьте `VLESS_SUBSCRIPTION_URL` и вставьте VLESS-ссылку. Не помещайте её в исходный код или GitHub. Ссылка уже раскрывалась в чате, поэтому для реальных продаж сначала смените UUID клиента в 3x-ui и используйте новую ссылку.

5. Цены по умолчанию: 75, 225, 450 и 900 Telegram Stars. При необходимости измените `STARS_PRICE_1M`, `STARS_PRICE_3M`, `STARS_PRICE_6M`, `STARS_PRICE_12M`; можно также задать `SUPPORT_USERNAME` без символа `@`.
6. В папке `telegram-bot` выполните:

   ```powershell
   npm install
   npm start
   ```

Покупатель отправляет `/start`, открывает магазин, выбирает тариф и продолжает в чате. После ознакомления с `/terms` покупатель подтверждает условия и получает счёт Telegram Stars. Доступ нельзя выдавать по `pre_checkout_query`: только событие `successful_payment` означает подтверждённую оплату. `/paysupport` отвечает на вопросы о платеже.

**Ограничение общего VLESS-профиля:** всем покупателям отправляется один UUID. Бот не может отключить доступ одного пользователя по истечении тарифа, а смена UUID затронет всех. Для персональных сроков подписки потребуется создавать отдельного клиента в 3x-ui для каждого заказа через API.
